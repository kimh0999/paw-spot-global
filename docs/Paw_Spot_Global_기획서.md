# Paw Spot Global 기획서 v2

> **v2 주요 변경점**
> - 1차 타겟을 "한국 거주 외국인 (영어권)"으로 명확화
> - 시장 사이즈 추정 (2025년 법무부 통계 기반)
> - 경쟁 서비스 분석 추가
> - 데이터 운영 모델 (지속 가능한 검증 프로토콜) 보완
> - 법적 면책 / 디스클레이머 명시
> - 수익 모델 가설 추가
> - 반려견 프로필 활용 방식 명확화 (필터 연동)
> - 일본어/중국어 P2 근거를 데이터로 보강

## 1. 서비스 개요

### 서비스명

**Paw Spot Global**

> *명칭 검토 사항*: 서비스 범위가 한국 한정이므로 향후 "Paw Spot Korea" 또는 "Paw Spot KR" 등으로 변경 검토 가능. v2 기획서에서는 기존 명칭을 유지.

### 한 줄 소개

**한국에 거주하거나 여행 중인 외국인 반려견 보호자가 반려견과 함께 갈 수 있는 음식점, 카페, 여행지를 영어로 쉽게 찾고, 방문 전 반드시 확인해야 할 조건을 명확하게 알 수 있는 반려견 동반 장소 안내 서비스.**

### 핵심 메시지

> "Pet-friendly"라고 적힌 장소가 정말 갈 수 있는 곳인지, 방문 전에 꼭 확인해야 할 조건을 영어로 한눈에 보여준다.

### 차별화 한 줄

> **네이버·카카오 리뷰는 "갔다온 사람의 말", Paw Spot Global은 "가기 전에 확인된 정보".**

## 2. 기획 배경

포털 사이트, 지도 서비스, SNS에는 "애견 동반", "반려견 가능", "Pet-friendly"라고 표시된 장소가 많지만, 실제로 방문해보면 조건이 다른 경우가 많다.

예를 들면,

- 실내는 불가능하고 야외 테라스만 가능한 경우
- 이동장이나 유모차가 있어야 입장 가능한 경우
- 소형견만 가능한 경우
- 중형견·대형견은 현장 상황에 따라 거절되는 경우
- SNS에는 가능하다고 되어 있지만 현재는 정책이 바뀐 경우

이 때문에 사용자는 방문 전에 매번 전화하거나 인스타그램 DM으로 확인해야 한다. 특히 외국인 사용자는 한국어로 문의하기 어렵고, 장소 설명이나 주의사항을 이해하기도 어렵다.

Paw Spot Global은 이 문제를 해결하기 위해 **반려견 동반 가능 장소의 핵심 조건을 구조화하고, 방문 전 확인해야 할 정보를 영어 중심으로 제공하는 서비스**다.

## 3. 문제 정의

| 문제 | 설명 |
|------|------|
| "애견 동반 가능" 정보가 너무 넓음 | 실제로는 실내 가능, 야외만 가능, 이동장 필수 등 조건이 다름 |
| 조건 확인이 번거로움 | 전화, 인스타그램 DM, 블로그 후기 확인을 사용자가 직접 해야 함 |
| 외국인은 정보 접근이 더 어려움 | 한국어 안내, 전화 문의, 매장 주의사항 이해가 어려움 |
| 현장 방문 실패 가능성 | 조건을 모르고 방문했다가 입장을 거절당할 수 있음 |
| TourAPI 정보만으로는 부족 | 반려동물 동반 유형은 알 수 있지만 세부 조건이 비어 있는 경우가 있음 |
| 정책 변경 감지 불가 | 매장 정책이 바뀌어도 기존 정보가 그대로 노출되는 경우가 많음 |

## 4. 시장 분석

### 4-1. 시장 사이즈 (2025년 말 기준)

법무부 출입국외국인정책본부 통계월보 기준 국내 체류 외국인은 **278만 명** (역대 최대, 전체 인구의 5.4%).

| 국적 | 인원 | 비율 |
|------|------|------|
| 중국 (한국계 포함) | 98만 명 | 35.2% |
| 베트남 | 33.7만 명 | 12.1% |
| 미국 | 18만 명 | 6.5% |
| 태국 | 17만 명 | 6.1% |
| 우즈베키스탄 | 10.3만 명 | 3.7% |
| 일본 (재한일본인) | 7만 명 | 2.5% |

### 4-2. 타겟 풀 추정

**영어 UI 기반 서비스로 접근 가능한 잠재 시장:**

- 영어권 체류 외국인 (미국, 캐나다, 영국, 호주, 아일랜드 등): 약 25만 명
- 영어 가능 비영어권 (인도, 필리핀, 유럽 일부): 약 5~10만 명
- **잠재 사용자 풀**: 약 30~35만 명

여기서 반려견 보유 + 외출 시 동반 + 앱 다운로드 의향을 고려하면 **활성 가능 사용자 풀은 약 1~3만 명**으로 추정.

추가로 단기 방문 외국인 관광객(2025년 약 1,800만 명 추정) 중 반려견 동반 여행자 비율이 점진적으로 증가하는 추세도 보조 시장으로 작용.

### 4-3. 왜 외국인 타겟인가

> 한국인 시장(반려견 양육 가구 약 600만)은 네이버 지도, 카카오맵, 다이닝코드 등에서 이미 "반려동물 동반 가능" 필터를 제공하고 있다. Paw Spot Global은 이들이 충분히 서비스하지 못하는 **한국어 정보 접근이 어려운 외국인 보호자의 미해결 페인포인트**에 집중한다.

### 4-4. 경쟁 서비스 분석

| 서비스 | 강점 | 약점 (우리의 기회) |
|--------|------|---------------------|
| 네이버 지도 | 사용자 리뷰 풍부, DB 큼 | 영어 미지원, 조건 비구조화, "가능/불가능" 이분법 |
| 카카오맵 | 위치 기반 검색 강력 | 영어 미지원, 반려동물 조건 정보 부족 |
| 다이닝코드 / 망고플레이트 | 음식점 큐레이션 | 반려동물 정보가 부가 태그 수준 |
| 댕댕플레이스, 페오펫 등 전용 앱 | 반려견 동반 특화 | 한국어 전용, 운영자 검증 약함, 외국인 접근 어려움 |

**Paw Spot Global의 포지셔닝**: 위 서비스 어느 곳도 동시에 만족시키지 못하는 영역에 집중 — 영어 UI + 운영자 검증 + 구조화된 방문 전 조건.

## 5. 서비스 목표

### MVP 목표

```
한국관광공사 TourAPI를 장소명, 주소, 좌표, 이미지 등 장소 기본정보의 1차 데이터 소스로 활용하고,
Paw Spot DB에서 운영자 검증 또는 관리자 입력 데이터와 결합하여
방문 전 핵심 조건이 구조화된 장소 정보를 영어 중심 UI로 제공한다.
```

### 핵심 검증 가설

| 가설 | 검증 방법 |
|------|-----------|
| 사용자는 "애견 동반 가능"보다 세부 조건을 더 원한다 | 사용자 인터뷰, 테스트 페이지 반응 |
| 외국인 사용자는 영어로 된 조건 요약을 필요로 한다 | 영어 UI 프로토타입 테스트 |
| 방문 전 3대 조건 정보가 가장 유용하다 | 실내 가능 여부, 이동장/유모차 필요 여부, 크기 제한 확인 |
| TourAPI는 후보 장소 수집에 유용하다 | API 데이터 수집 후 후보 장소 DB 구축 |
| 운영자 검증 데이터가 서비스 신뢰도를 높인다 | 확인일, 확인 방법 표시 |
| 시드 30~50곳 검증으로 초기 사용자 만족도를 확보할 수 있다 | 베타 사용자 NPS 측정 |

### 초기 지리적 범위

전국이 아닌 **시드 지역 집중**:
- 서울 (이태원, 한남동, 홍대, 강남 일부): 외국인 거주·방문 밀집
- 또는 본 개발자 거점 지역(대전) 일부

목표는 시드 지역에서 **30~50곳을 완벽하게 검증**하는 것. 전국 광역 데이터는 P2 확장 단계.

## 6. 핵심 타깃 사용자

### 1차 타깃

**한국에 거주하거나 장기 체류 중인 외국인 반려견 보호자 (영어 사용자)**

페르소나 예시:
- 한국어가 익숙하지 않음
- 반려견과 카페, 음식점, 여행지를 찾고 싶음
- 포털 사이트나 SNS 정보를 신뢰하기 어려움
- 전화 문의보다 영어 안내와 확인 문구를 선호함

### 2차 타깃

**한국 여행 중 반려견 동반 장소를 찾는 외국인 관광객**

단, MVP에서는 해외에서 반려견을 데리고 입국하는 검역, 항공, 등록 절차까지는 다루지 않음.

### 부가 사용자 (메인 타겟 아님)

**한국어 UI를 통해 접근하는 한국인 반려견 보호자**

한국어 UI를 함께 제공하기 때문에 한국인 사용자도 자연스럽게 유입될 수 있음. 다만 한국인 사용자에 특화된 기능(주차, 평일/주말 혼잡도 등)은 MVP에서 우선순위로 두지 않음.

## 7. 서비스 핵심 기능

### 7-1. 반려견 동반 가능 장소 검색

사용자는 장소를 카테고리별로 탐색할 수 있다.

| 카테고리 | 설명 | MVP 포함 여부 |
|----------|------|----------------|
| 음식점 | 반려견 동반 가능한 식당 | 포함 |
| 카페 | 실내 또는 야외 반려견 동반 카페 | 포함 |
| 여행지 | 관광지, 공원, 산책 가능 장소 | 포함 |
| 숙소 | 반려견 동반 숙소 | **P2 이후** (조건 구조가 달라 별도 설계 필요) |
| 기타 | 쇼핑, 문화시설 등 | P1 |

> **숙소 카테고리 분리 이유**: 숙소는 예방접종 증빙, 추가 요금, 동반 두수 제한, 가구 보호 정책 등 음식점/카페와 완전히 다른 조건 구조를 가짐. 어설프게 포함하기보다 별도 모델로 P2에서 다룸.

---

### 7-2. 방문 전 필수 확인 정보 (핵심 기능)

이 기능이 Paw Spot Global의 핵심이다. 단순히 "반려견 동반 가능"이라고 표시하지 않고, 사용자가 방문 전에 꼭 확인해야 하는 조건을 구조화해서 보여준다.

**핵심 확인 항목:**

| 항목 | 옵션 |
|------|------|
| 실내 동반 가능 여부 | 실내 가능 / 야외석만 가능 / 불가 / 확인 필요 |
| 이동장·가방·유모차 조건 | 불필요 / 이동장 필수 / 유모차 가능 / 확인 필요 |
| 크기 제한 | 소형견 가능 / 중형견 가능 / 대형견 가능 / 확인 필요 |
| 견종 제한 | 제한 없음 / 특정 견종 제한 / 확인 필요 |
| 준비물 | 목줄, 배변봉투, 이동장, 유모차 등 |
| 주의사항 | 짖음 통제, 단독 방치 금지, 테이블·의자 위 금지 등 |
| 마지막 확인일 | 운영자 확인 날짜 표시 |
| 확인 방법 | 전화 / 인스타그램 DM / 공식 홈페이지 / 방문 확인 |

**중요한 디스클레이머 (모든 상세 페이지에 표시):**

```
This information was verified on [date] through [method].
Store policies may change. We recommend confirming with the store
before your visit, especially for special circumstances.
```

### 7-3. 반려견 프로필 (필터 연동)

MVP에서는 복잡한 체중 기반 자동 판정을 하지 않는다. 대신 사용자가 간단하게 반려견 정보를 등록하면, **"내 반려견이 갈 수 있는 곳만 보기" 필터**가 자동 적용된다.

**입력 항목:**

| 항목 | 설명 |
|------|------|
| 이름 | 반려견 이름 |
| 크기 | 소형견 / 중형견 / 대형견 |
| 견종 | 선택 또는 직접 입력 |

**필터 연동 동작:**
- 중형견 등록 → 소형견 한정 매장은 결과에서 자동 제외 또는 회색 처리
- 견종 제한이 있는 매장은 별도 표시

체중, 예방접종, 성격은 매장 조건과 매칭하기 어려워 MVP에서 제외.

### 7-5. 영어 중심 다국어 UI

| 언어 | MVP 포함 여부 | 근거 |
|------|---------------|------|
| 영어 | 포함 (메인) | 1차 타겟 언어 |
| 한국어 | 포함 (보조) | 한국인 보호자 부가 유입, 운영자 입력용 |
| 일본어 | **P2 이후** | 재한일본인 약 7만 명, 잠재 사용자 풀 작음 |
| 중국어 | **P2 이후** | 중국인 98만 명으로 잠재 시장은 크지만, 1인 개발 MVP에서는 번역·검증 부담이 과도 |

번역 대상은 단순 메뉴가 아니라 실사용 정보:
- 장소명, 장소 설명
- 방문 전 확인 조건
- 준비물, 주의사항
- 문의 문구, 긴급 상황 문장

### 7-6. 한국어 문의 문구 제공

외국인 사용자는 매장에 직접 문의하기 어렵기 때문에, 복사해서 보낼 수 있는 한국어 문구를 제공.

**예시:**

```
안녕하세요. 반려견 동반 가능 여부를 확인하고 싶습니다.

1. 실내 공간에도 반려견이 들어갈 수 있나요?
2. 이동장이나 유모차가 필수인가요?
3. 소형견, 중형견, 대형견 제한이 있나요?
4. 특정 견종 제한이 있나요?

감사합니다.
```

**영어 안내:**

```
Copy this Korean message and send it to the store
by Instagram DM or phone.
```

이 기능은 영어 UI에서만 메인 영역에 노출되고, 한국어 UI에서는 숨김 처리.

### 7-10. 구조화 리뷰 (운영 백본)

리뷰는 자유 텍스트보다 체크박스 중심으로 받는다. **이 데이터는 단순 리뷰가 아니라, 운영자 검증 데이터의 정확성을 지속적으로 보정하는 백본 역할**을 한다.

**리뷰 항목:**
- 실제로 반려견 입장이 가능했나요?
- 실내 이용이 가능했나요?
- 직원 안내가 명확했나요?
- 외국어 소통이 가능했나요?
- 해외 카드 결제가 가능했나요?
- 다시 방문하고 싶나요?
- 한 줄 후기

**리뷰 → 재검증 트리거:**
"실제로 반려견 입장이 불가능했다"는 리뷰가 일정 수 이상 누적되면 자동으로 해당 장소의 상태를 "재확인 필요"로 표시하고, 운영자에게 알림.

리뷰 사진 업로드는 MVP에서 제외 (Storage, 신고, 검수, 용량 관리 부담).

## 8. 데이터 전략

### 8-1. TourAPI 활용 (장소 기본정보의 1차 데이터 소스)

한국관광공사 반려동물 동반여행 API를 활용해 장소 기본정보를 수집한다. TourAPI는 Paw Spot 장소 데이터 구축의 출발점이다.

**활용 API:**
- areaBasedList2
- searchKeyword2
- detailCommon2
- detailPetTour2
- detailImage2

**TourAPI에서 가져오는 데이터:**
- 장소명, 주소, 좌표
- 대표 이미지
- 콘텐츠 타입
- 기본 설명
- 반려동물 동반 유형
- 반려동물 동반 관련 기본 정보

TourAPI에서 수집한 기본정보는 Paw Spot DB에 저장된다. 단, 실내 가능 여부, 이동장 필수 여부, 크기 제한, 견종 제한, 마지막 확인일 같은 핵심 조건은 TourAPI만으로 부족할 수 있다. Paw Spot DB에서 운영자 검증 데이터와 결합해 최종 서비스 데이터로 완성하며, 사용자는 TourAPI 원본이 아니라 Paw Spot에서 구조화·검증한 데이터를 보게 된다.

### 8-2. 관리자 검증 데이터

**입력 항목:**
- 장소 분류, 운영시간
- 실내 동반 가능 여부, 야외석 가능 여부
- 이동장 필요 여부, 유모차 가능 여부
- 소형견 / 중형견 / 대형견 가능 여부
- 견종 제한 여부
- 필수 준비물, 주의사항
- 확인 방법, 확인일

**확인 방법:**
- 전화 확인
- 인스타그램 DM 확인
- 공식 홈페이지 확인
- 방문 확인
- 사용자 신고 기반 재확인

### 8-3. 지속 가능한 데이터 운영 모델

1인 개발자가 운영하는 검증 모델은 **장소 수의 한계가 존재한다**. 다음과 같이 단계별로 운영한다:

**Phase 1 (~50곳): 운영자 100% 검증**
- 전화 / DM / 홈페이지로 직접 확인
- 시드 지역 집중 (예: 이태원 + 한남동)
- 각 장소 검증 시간: 평균 10~15분

**Phase 2 (50~150곳): 운영자 + 매장 사장 직접 입력**
- B2B 등록 페이지를 통해 매장 사장이 직접 정책 등록 가능
- 운영자는 검수 역할로 전환
- 정확도 보장을 위해 사장 입력 항목도 운영자 1차 검증 후 노출

**Phase 3 (150곳~): 크라우드소싱 + 가중치**
- 사용자 신고가 일정 수 누적되면 자동 재확인 트리거
- 최근 방문 사용자 리뷰의 신뢰도 가중치 부여
- 운영자는 분쟁 조정과 신규 검증에 집중

**재확인 주기:**
- 기본 6개월
- 신고 3건 이상 누적 시 즉시
- 사용자 리뷰에서 정책 불일치 발견 시 우선 확인

### 8-4. 데이터 처리 흐름

```
TourAPI 장소 기본정보 수집
→ Paw Spot DB에 원본/후보 데이터 저장
→ 운영자 검증 또는 관리자 입력
→ 반려견 동반 조건 구조화
→ visibility=VISIBLE인 장소만 사용자에게 노출
→ 리뷰/신고 기반으로 재확인 필요 상태 관리
```

## 9. 법적 면책 및 리스크 관리

### 9-1. 디스클레이머

모든 장소 상세 페이지에 다음 문구를 영어와 한국어로 표시:

```
This information was verified on [date] and may change without notice.
Paw Spot Global does not guarantee admission. Please confirm with the
store before your visit, especially for special circumstances such as
large breeds, group bookings, or peak hours.
```

### 9-2. 약관 핵심 조항

- 본 서비스는 매장의 입장 가능 여부를 보장하지 않으며, 안내된 정보를 바탕으로 한 사용자의 방문 결과에 대해 책임을 지지 않는다.
- 모든 정보는 확인일 기준이며, 매장의 운영 정책 변경에 따라 달라질 수 있다.
- 사용자가 부정확한 정보를 발견한 경우, 신고 기능을 통해 재확인을 요청할 수 있다.

### 9-3. 매장 측 요청 대응

- 매장이 정보 수정 또는 등록 해제를 요청하면 영업일 기준 3일 이내 처리
- 잘못된 정보로 인한 매장의 피해 신고 채널 운영

## 14. 서비스 차별점

1. "애견 동반 가능"을 그대로 보여주지 않고, **방문 전 필요한 조건으로 구조화**한다.
2. **외국인이 이해할 수 있도록 영어 중심 UI**를 제공한다.
3. **실내 가능 여부, 이동장/유모차 필요 여부, 크기 제한**이라는 핵심 조건을 빠르게 확인할 수 있다.
4. **한국어 문의 문구**를 제공해 전화나 인스타그램 DM 확인 부담을 줄인다.
5. **TourAPI를 장소 기본정보의 1차 데이터 소스로** 활용하고, 운영자 검증 데이터를 결합해 실제 방문 의사결정에 필요한 조건 정보로 재가공한다. 단순 공공데이터 목록 서비스가 아니라, **검증 조건 중심의 반려견 동반 장소 안내 서비스**임을 강조한다.
6. **마지막 확인일과 확인 방법**을 명시해 사용자가 정보의 신선도를 판단할 수 있다.
7. **사용자 리뷰가 재확인 트리거로 작동**해 시간이 지나도 정보가 자동으로 보정된다.

## 15. 기대 효과

### 사용자 기대 효과

- 한국어를 잘 몰라도 반려견 동반 장소를 찾을 수 있음
- 방문 전 핵심 조건을 빠르게 확인할 수 있음
- 실내 불가, 이동장 필수, 소형견 제한 등으로 현장에서 거절당할 가능성을 줄임
- 매장에 문의할 때 사용할 수 있는 한국어 문구를 바로 복사할 수 있음
- 응급 상황에서 필요한 기본 문장을 사용할 수 있음

### 서비스 기대 효과

- TourAPI 데이터를 단순 노출하지 않고 실제 방문 판단에 필요한 조건 데이터로 재가공
- 외국인 반려견 보호자라는 명확한 타깃 확보
- 장소 기본정보와 검증 조건을 결합한 자체 데이터 자산을 축적
