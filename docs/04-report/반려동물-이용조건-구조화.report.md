## 3. 겪은 문제와 원인

| 문제 | 원인 | 대응 |
|---|---|---|
| 같은 장소를 화면마다 다르게 말함 | 목록만 요약 컬럼을 직접 읽고 `policyDetails`를 안 봄 | 판정 근거를 `resolveDogAccess` 한 곳으로 모음 |
| 테스트가 결함을 고정 | `실내 미확인 → MATCH` 단언. 의도(불가로 보지 말 것)는 맞았으나 표현이 과함 | `CHECK_REQUIRED`로 바로잡고 이름도 두 사실을 담게 고침 |
| favicon 요청마다 홈 렌더 | 미들웨어 matcher가 점 있는 경로를 건너뛰지만 라우트는 매칭됨 | 파일 규약 + `assertSupportedLocale` 두 겹 |
| 잘못된 잔여 항목 보고 | 옛 분석의 미완료 항목을 재확인 없이 이월 | 분석 문서에 철회 근거와 오독 경위를 남김 |

## 4. 배운 것

- **분석 문서의 미완료 항목은 이월 전에 코드로 재확인한다.** N-3은 5일 전에 닫힌 항목이었다.
- **테스트가 요구사항을 잘못 적으면 결함이 고정된다.** F-1의 실패 원인은 코드보다 테스트였다.
- **"레이아웃에서 막았으니 조회도 안 될 것"처럼 추정하지 않고 센다.** 요청별 `prisma:query` 수를
  세어 확인했다.
- **결정 ID는 부여 전에 기존 문서를 확인한다.** `D-13`은 이미 예약돼 있어 `D-15`로 바꿨다.
